## 📌 Project Overview

This project investigates the **Customer Churn Prediction** problem using the IBM Telco Customer Churn dataset. The objective is to identify customers who are likely to leave the company based on demographic information, subscribed services, contract details, and billing history.

The project follows a complete machine learning pipeline:

- 📊 Exploratory Data Analysis (EDA)
- 🧹 Data Cleaning & Preprocessing
- ⚙️ Feature Engineering
- 📉 Dimensionality Reduction (PCA, Kernel PCA, LDA, t-SNE)
- 🤖 Machine Learning Models
  - Logistic Regression
  - Support Vector Machine (RBF Kernel)
  - Random Forest
- 🔍 Hyperparameter Optimization
- 📈 Model Evaluation
- 📊 ROC Curve, AUC, Learning Curve and Feature Importance Analysis

The final model was selected based on comprehensive evaluation metrics rather than accuracy alone, emphasizing recall, AUC-ROC, confusion matrix analysis, and model generalization.
